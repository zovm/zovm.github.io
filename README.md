# 敏，冬日暖阳

属于两个人的互动圣诞主页与生活记录小站。恋爱起点：**2025 年 12 月 9 日（北京时间零点）**。

## 体验

- 约 12 秒开场：下雪、枝叶自下而上展开、灯串依次点亮、树顶星星发光、彩色光点环绕。
- 点击星星许愿；纸条化作星光飞向树顶；再次点击可查看、删除本机心愿。
- 三个礼物：牵手照片、圣诞信、可在本机保存的约定打卡。
- 点击情侣产生爱心；轻触树身产生星光。
- 原创轻柔合成钟琴音乐，默认关闭，点击后播放。
- 手机与电脑适配；支持键盘与减少动态效果；后台标签页暂停绘制。

## 页面与导航

首页为全屏圣诞树，保留第一版绘制风格，仅加粗枝干、增加少量装饰。上方为半透明渐变标题，左侧为放大相恋计时。远处为雪夜小镇，近处为牵手的两个人。

左上角三横线菜单包含：首页、dailyM、照相馆、gameM。

- 照相馆：Love 分类包含用户指定文件夹的 4 张照片，照片以环形动态排列，可拖动、暂停与正向放大浏览。
- `dailyM.html`：记录日期、标题、心情和生活文字，支持编辑、删除、搜索、导出和导入备份。
- `gameM.html`：记录游戏名、游玩日期、分钟数和感想，支持相同的编辑和备份能力。

两类记录均仅保存在当前浏览器，每类最多 200 条；并不跨设备同步。

## 文件与部署

纯 HTML、CSS、JavaScript，无需安装依赖或构建。

将本目录文件上传到 `zovm/zovm.github.io` 的 `main` 分支，在仓库 Settings → Pages 选择 **Deploy from a branch / main / (root)**。

也可以在本目录运行 `python -m http.server 4173`，访问 `http://localhost:4173/`。

- `index.html`：文字、页面结构及交互入口。
- `style.css`：配色、布局、礼物和纸条样式。
- `app.js`：树与雪动画、纪念日计时、本地心愿、礼物互动与音乐。
- `assets/couple.png`：基于用户提供的牵手影子照片生成的透明情侣剪影。
- `assets/our-memory.jpg`：用户指定的原始牵手影子照片。

## 本地数据

心愿保存在当前网站来源的 `localStorage`，键为 `our-christmas:wishes:v1`；打卡为 `our-christmas:promises:v1`。每个心愿最多 240 字，最多保存 30 条。数据不上传服务器，不跨设备同步；清除浏览器网站数据后会消失。本地预览与正式域名的数据各自独立。保存失败时页面会提示，保留输入文字。

## 素材说明

透明情侣素材使用内置图像生成工具，以用户指定照片为参考制作。使用的提示概要：保留原图左侧长发较矮人物、右侧较高人物及牵手姿态；移除地面与环境；将过长影子整理为完整站立的冬日长外套情侣；深蓝剪影配轻微暖金边缘；无脸部细节、无文字、真实透明背景。树、灯、雪、礼物均由网页直接绘制。远景小镇由内置图像生成工具制作，提示概要为：深蓝雪夜、积雪小镇、房窗暖光、远处散步情侣与玩耍的孩子、空旷前景供独立圣诞树和情侣叠加。最终使用优化的 WebP 背景；未采用后续生成的写实圣诞树素材。
