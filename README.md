# 曾❤敏

情侣主页与回忆小站，发布于 https://zovm.github.io/ 。相恋起点为北京时间 **2025 年 12 月 9 日零点**。

## 页面

- `index.html`：首次访问以树的开场进入，随后进入双头像主页。也可使用 `?home=1` 直接进入主页。主页提供相恋计时和 dailyM、照相馆、gameM、foodM 四个入口。
- `welcome.html`：保留最初绘制的圣诞树、渐进亮灯与环绕光。人物出现后，从左到右打出“敏，冬日暖阳”；可许愿、拆礼物、重播。
- `gallery.html`：分类封面、环形旋转照片、拖动浏览、正向放大。分类为 Love（7 张）、牵手的瞬间（1 张）、情侣头像（8 张）、food · 甜蜜食光（1 张）、drink · 饮品时光（2 张）和视频日记（3 段）。照片点击后正向放大，视频点击后使用原生播放器播放，关闭预览停止视频；播放视频会暂停背景歌单。素材信息由 `assets/gallery/albums.json` 维护。
- `dailyM.html`：记录日常与情侣相伴的时光。
- `gameM.html`：记录一起游玩的游戏。
- `foodM.html`：默认打开“喜欢的”，另有每日饮食和不喜欢／忌口；可按奶茶、食物、饮料筛选，标记曾、敏或我们，以及餐次。
- `record.html?kind=...&id=...`：每条记录有独立网址，支持正文、照片与视频，以及编辑、删除和全屏预览。
- `city.html?city=...`：按城市收藏旅行文字、照片与视频；可从地图上选中城市进入。

左侧三横线菜单提供主页和全部页面入口，标题为“曾❤敏”。除圣诞树开场外，底部署名为斜体 *launched by Z&M*。

## 配色

默认使用樱花粉、淡紫与天空蓝渐变。右上角可切换渐变、樱花粉、天空蓝、薰衣草、蜜桃橙。选择保存在本浏览器并跨页面生效。 圣诞树开场的小镇使用固定的清晰度和暖色灯火，顶部天空渐隐融入所选主题，避免浅色主题冲淡房屋细节。

## 音乐

右上角音符打开“我们的歌单”。6 首歌曲来自用户指定的 `M:\CloudMusic\VipSongsDownload`：玻璃、i hate u, i love u、目及皆是你、慢慢、想想念念、某年某月某天。原文件不改动，网页播放副本位于 `assets/music/`。

可勾选播放列表、点歌、切换上一首和下一首、拖动进度、调整音量，支持顺序播放、随机播放和单曲循环。当前浏览器记住歌单、音量、模式及播放位置；首次播放需点击。歌曲按需加载，不影响开场动画。`assets/music/playlist.json` 管理歌曲信息。

## 数据

记录与媒体先保存在当前网站来源的 IndexedDB（`zengmin-memories`，版本 2）。未连接 GitHub 也能添加内容；连接后可以把本地内容同步到网站，在其他设备访问。旧版 IndexedDB 和 localStorage 记录会自动迁移，已有图片保留；迁移标记避免重复导入已删除的旧记录。

每条记录最多 20 个照片或视频，每个文件不超过 50 MB。支持 JPG、PNG、WebP、MP4、WebM、MOV；图片会优化，视频保留原文件并尝试生成封面。视频能否播放取决于浏览器对其编码的支持，无法播放时可下载。备份包含文字、媒体和封面；账号窗口可导出全部回忆，各列表也可分别导出，导入保留现有记录并合并新记录，兼容旧版备份。

## GitHub 账号与同步

foodM 已收录敏的 15 项口味：7 项喜欢的奶茶、5 项喜欢的食物、桃子酒，以及不喜欢的沪上阿姨芒芒椰椰和啤酒。茉莉奶绿仍归喜欢，保留用户原写的 2026-7.7 备注；杨枝甘露保留“避雷蜜雪”，伯牙绝弦注明霸王茶姬，芒芒椰椰保留“过甜吃吐了”。口味档案的日期标为收录日期，2026-7.7 只作为该条目的历史备注。

类别和品牌可在记录详情中编辑，正文仍可写备注并添加图片。类别与品牌以普通文字保存在备注开头，旧客户端同步、导出和导入也会保留这些信息；新版界面将它们显示为条目的类别、品牌，不重复显示在正文中。

日记列表、记录页、照相馆和旅行地图的操作统一收进右下角“＋”：点击展开新增、导入/导出备份、GitHub 连接及同步，再次点击、点空白处或按 Escape 收起。左侧菜单也可以打开“GitHub · 账号与同步”。照相馆的菜单位于相册弹层内部，打开照片预览或其他窗口后不会挡住内容。

1. 点击“前往 GitHub 登录并授权”，在 GitHub 官方页面登录有仓库写入权限的账号。
2. 选择 Only select repositories，再选 `zovm.github.io`，将 Contents 设为 Read and write，然后生成令牌。
3. 将令牌粘贴到网站的连接窗口，点击“连接”。网站会校验账号和实际上传权限。
4. 点击“同步到网站”，发布本机待同步内容。已连接时，记录编辑器默认“保存并同步”，也可选择“仅存本地”。

账号密码只在 GitHub 官方页面输入。网站采用个人授权令牌，不提供自建密码验证或一键 OAuth 登录。令牌仅存于当前标签页的 sessionStorage，跨页面使用，退出连接后清除；不会写入仓库、备份或网址。请只使用对本仓库具有 Contents 读写权限的授权。

同步适用于 dailyM、gameM、foodM、照相馆的新分类/子相册和照片视频，以及七座旅行城市中的回忆。原有静态相册保留。照相馆的“＋”菜单在分类页提供新建相册/分类，在相册内提供添加照片/视频；每组新增内容都有自己的记录详情。

旅行地图选中城市后，城市卡片提供“添加回忆”和“查看回忆”，右下角菜单也会切换到这个城市。添加支持文字、照片与视频，按城市独立显示；打开操作菜单或移入城市卡片时暂停旅程，避免添加过程中城市自动切换。城市卡片恢复可点击，页面上方不再单独显示连接和同步按钮。手机底部城市条可横向滑动，为右下角菜单留出位置。

同步内容写入公开仓库并在网站公开展示。发布清单位于 `content/index.json`，媒体使用不可变编号写入 `content/media/`。未登录访客也可以读取已发布内容，登录授权只控制上传能力。

上传通过 GitHub Git Data API 创建媒体、目录树和单次提交，最后以非强制方式更新 main。所有文件就绪后才更新网站；断网或授权失败时保留本地待同步内容。合并基于记录版本，保留其他设备的独立新增；同一条记录同时修改会另存一份，删除遇到较新修改时优先保留内容。删除使用版本化标记，不删除其他记录的媒体。原有网页源文件不参与内容同步。

`sync-model.js` 负责数据校验与合并，`memories.js` 负责本地保存与迁移，`sync-client.js` 负责固定仓库上传，`sync-ui.js` 提供连接和同步界面。网站内容提交后，GitHub Pages 需要短暂构建才能让所有访客看到最新版本。

愿望、约定打卡仍使用原 localStorage 键，升级时保留。换浏览器、换设备或清除网站数据将影响本机保存的内容。

参考用户提供的双头像卡片截图，以及开源情侣主页常见的“双头像、爱心、相恋计时”结构，未复制其他项目的实现。

开场的“进入主页”仅在树、灯光、环绕光、人物及标题动画完成，并且场景图片加载结束后淡入；重播会重新等待。开启减少动态效果时直接展示完成的场景，再显示入口。

## 旅行轨迹与纪念日

`travelM.html` 展示新余、南昌、长沙、上饶、衢州、绍兴、南京，按用户给出的顺序连线；支持逐站播放、暂停、重播、点击城市，以及全国视图和足迹放大。连线是城市间的示意，不代表真实道路或出游日期。

地图边界和城市中心来自 [DataV.GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)，原始边界接口为 `https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json`，城市行政区编码依次为 360500、360100、430100、361100、330800、330600、320100。本地化的向量数据位于 `assets/travel/map.json`，不依赖访问者连接地图服务，包含省级边界和南海诸岛附图。

主页在相恋计时下方增加整行的周年纪念日倒计时。每年按北京时间 12 月 9 日零点计算周年，当天显示周年祝福，12 月 10 日切换至下一年。
